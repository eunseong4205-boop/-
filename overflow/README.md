# 무한 렙업: OVERFLOW

캡(한계 레벨)이 **NULL**로 태어난 소년 제로가, 말하는 빨간 버튼을 누르며 레벨 1에서 세계의 한계 수 `1.79e308`을 넘어서는 이야기.
「무한으로 렙업하자!!」 스타일(버튼 연타 → 레벨·골드 → 전직 → 구슬 비번 → 사천왕 → 챔피언 → 엔딩)을 참고한 **오리지널** 모바일 클리커 RPG입니다. 캐릭터·세계관·스토리·픽셀 아트는 모두 새로 만들었습니다.

- 플레이: 저장소 루트의 [`overflow.html`](../overflow.html) 하나만 열면 됩니다 (외부 파일 없음, 폰 브라우저 OK).
- 저장: 브라우저에 15초마다 자동 저장. [더보기 → 설정]에서 저장 코드로 다른 기기로 옮길 수 있습니다.

## 게임 구성

| 시스템 | 내용 |
| --- | --- |
| 레벨업 | 전투 화면을 누를 때마다 경험치 + 공격. 레벨은 `1 → 1e90+`까지 치솟습니다 (만·억·조·경… 무량대수 표기) |
| 스탯 | 힘·체력·민첩·지능·행운. 자동 분배(비율 조절) / 수동 분배 |
| 전직 | 백수(5) → 알바생(10) → 모험가(15) → 용사(20) → 먼치킨(25) → 사기캐(30) → 밸런스 붕괴(40), 총 145차 |
| 구슬 · 비번 | 24개의 숨겨진 구슬. 같은 색 구슬 숫자의 **합**이 다음 전직 계열의 비밀번호 |
| 지역 | 11개 마을 × 30구역 + 종장. 5구역마다 우두머리, 30구역마다 스토리 보스 |
| 보스 | 제한 시간 + 보스의 반격(체력 스탯 필요). 사천왕 4명과 챔피언, 그리고 천장 |
| 유물 | 마을 보스 첫 격파 시 영구 유물 11종 |
| 동료 | 이야기 속 인물 10명이 합류해 자동 전투 |
| 장비 | 무기·갑옷·반지·목걸이. 25/100강마다 2배, 이름 변화 |
| 스킬 | 전직 계열마다 1개, 총 7개 (ALL 버튼으로 동시 사용) |
| 환생 | 버튼을 「길게」 눌러 리셋 → 기억 조각 → 영구 강화 12종 |
| 마을 | NPC 대화, 탐색 지점, 도박선 슬롯, 설정집 |
| 기타 | 업적 81개, 몬스터·인물 도감, 이야기 다시 보기, 오프라인 보상, 효과음(합성), 진동 |

## 플레이 시간

`tools/sim.js`가 실제 게임 엔진을 봇으로 플레이해 엔딩까지 걸리는 시간을 잽니다 (스토리 읽는 시간 제외).

| 봇 설정 | 엔딩까지 |
| --- | --- |
| 초당 5탭, 최적 구매·환생 | 약 5시간 20분 |
| 초당 3탭 | 약 5시간 50분 |
| 초당 2탭 | 약 6시간 20분 |

사람은 이야기(52개 장면)를 읽고, 구슬을 찾고, 최적이 아닌 선택도 하므로 실제로는 **6시간 반 ~ 8시간** 정도를 예상합니다.

## 개발

```bash
node overflow/tools/build.js          # src → ../overflow.html (+ 아티팩트용 dist/)
node overflow/tools/sim.js 5 12 2     # 탭/초, 최대 시간(h), 상세도(0~2)
SIM_B='{"relicK":0.07}' node overflow/tools/sim.js 5 12 0   # 밸런스 상수 덮어쓰기
```

```
overflow/src/
  body.html, style.css
  js/num.js      숫자 표기 (만·억·조 … 무량대수, e표기, K·M·B)
  js/data.js     밸런스 상수, 마을·몬스터, 전직, 구슬, 장비, 동료, 스킬, 업적
  js/engine.js   게임 상태·공식·틱 (DOM 없음, Node에서도 동작)
  js/story.js    인물, 장면 대본, NPC 대사, 탐색 지점, 설정집
  js/sprites.js  16×16 초상화 24종 + 절차적 몬스터 (5가지 체형)
  js/audio.js    WebAudio 8비트 효과음
  js/ui.js       전투 캔버스, HUD, 탭, 대화, 모달
  js/main.js     루프, 저장/불러오기, 오프라인 보상
```

밸런스의 핵심 손잡이는 `data.js`의 `B`에 있습니다: `relicK`(유물이 다음 마을 난이도를 얼마나 상쇄하는지), `fragPhi`(환생 조각 증가율), `clsK`(전직 배율), `diffEps`(보상 대비 난이도 가산).
